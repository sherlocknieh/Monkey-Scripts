## 开发指南

- **创建项目**
    ```bash
    npm create monkey
    ```

- **开发调试**
    ```bash
    pnpm i
    pnpm dev
    ```
    浏览器打开 `http://localhost:5173`，即可实时预览和调试脚本。


- **打包构建**
    ```bash
    pnpm build
    ```
