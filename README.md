## 本仓库中的简单脚本

### DeepSeek-KaTeX-Copy-Fix
- 描述: 修复 DeepSeek 中的 KaTeX 公式复制问题
  DeepSeek 网页端的 LaTeX 公式是用 KaTeX 渲染成的 HTML 元素，直接复制得不到完整的公式, 需引入 KaTeX-copy 插件才有用. Deepseek官方没有引入这个插件, 所以用脚本来简单修复一下
  
- 安装: https://github.com/sherlocknieh/Monkey-Scripts/raw/main/simple-scripts/deepseek-katex-copy-fix.user.js
